사이트 URL · 협력자 코드 확인 방법

스토어를 추가할 때 입력하는 사이트 URL과 협력자 코드(보안 코드)를 확인하는 방법입니다.

💡 미리 알아두기
사이트 URL은 nnnnn-nn.myshopify.com 형식이고, 협력자 코드는 쇼피파이 사용자 → 보안 화면의 보안 코드 값입니다.
STEP 1설정 열기

쇼피파이에 로그인한 뒤, 왼쪽 아래의 설정을 클릭합니다.

STEP 2Domains(도메인) 열기

설정 목록에서 Domains(도메인)을 클릭합니다.

STEP 3사이트 URL 확인

nnnnn-nn.myshopify.com 형식으로 된 URL이 사이트 URL입니다. 이 주소를 스토어 추가 시 스토어 URL 칸에 입력하세요.

STEP 4협력자(보안) 코드 확인

사용자 → 보안으로 이동해 보안 코드 칸의 값을 확인합니다. 이 값이 협력자 코드입니다.

✅ 정리
스토어 추가 화면에서 스토어 URL에는 STEP 3의 myshopify.com 주소를, 협력자 코드에는 STEP 4의 보안 코드를 입력하면 됩니다.
